# Contributing

`README.md` says what Substrate is; `AGENTS.md` is the fastest orientation to the layout and the
boundaries that are not obvious from the code.

## Setup

Go (the version in `go.mod`), `git`, and Python 3 for `scripts/scan-public`.

## The sequence

1. Branch as `<type>/<short-slug>` (`feat`, `fix`, `docs`, `chore`).
2. Change one thing. A new capability is a module under `modules/<name>/` plus a catalogue entry in
   `catalog/catalog.go`; keep it optional and never let it own identity, policy, data or listeners.
3. When done, run `go vet ./...`, `go test ./...` and `python3 scripts/scan-public --ref HEAD`.
4. Open a pull request. Commit subjects use the conventional-commit shape (`feat(health): ...`).

## What a pull request carries

What the change does, what it leaves alone, and the evidence: commands you ran and what came back. If a
number appears, put the command that produced it beside it.

## Cannot be undone

- **A pushed tag.** The Go module proxy caches every version it serves; a fetched tag cannot be reused or
  withdrawn, only superseded. Only a maintainer tags. Write the `CHANGELOG.md` section first.
- **Anything committed to this public repository.** Secrets, internal host names or addresses and personal
  paths stay in history. Run `scripts/scan-public` before pushing; do not allowlist a finding without a stated reason.

## Things that surprise people

- **Generated wiring.** `examples/*/substrate_wiring.go` is generated by `substrate generate`; edit the
  manifest, not the file.
- **Excluded means not linked.** The builder only imports selected modules; do not import a module from
  another module's non-test code unless the catalogue lists it under `Requires`.
- **Pins live in `bom/bom.yaml`.** Do not pin versions anywhere else.
